Code Log 2: CSS Measuring Units.

The difference between absolute CSS length units and relative CSS length units are rather simple.

Absolute units are units that do not change no matter what you do to the webpage.

Relative units adjust and change when you alter the webpage in any form.

For an example pixels px and points pt are both absolute units.

One pixel represents 1/96 of a inch.

One point represents 1/72 of a inch.

Pixels are better for screens.

Points are better for printing stuff.

Inches in and picas pc are also absolute units.

1 inch = 96 pixels.

1 picas = 12 points.

VW and VH are relative CSS length units.

These units will adjust and change to match whatever you do to the webpage.

VW is relative to 1% of the width of the viewport.

VH is relative to 1% of the height of the viewport.
